## ✨ Features

| Feature | Description |
|--------|-------------|
| 🔐 **Multi-user Login** | Email/password authentication via Firebase |
| 📖 **Subject Tracker** | Track chapters completed per subject with progress bars |
| 📅 **Exam Countdown** | Add exams and see live day countdowns |
| ✅ **Habit Tracker** | Build daily study habits with check-off system |
| ⏳ **Pomodoro Timer** | Animated focus timer with short & long break modes |
| ⭐ **XP & Level System** | Earn XP for every action and level up |
| 🔥 **Streak System** | Track consecutive days of studying |
| 🏆 **Achievements** | 8 unlockable badges for milestones |
| 📊 **Analytics** | Charts for subject progress, habits & exam countdowns |
| 🌙 **Dark Mode** | Toggle between cozy light and dark themes |
| ☁️ **Cloud Sync** | All data saved to Firebase Firestore — works on any device |

---

## 🛠️ Built With

- **HTML, CSS, JavaScript** — Pure vanilla, no frameworks
- **Firebase Authentication** — Secure email/password login
- **Cloud Firestore** — Real-time database for user data
- **Chart.js** — Beautiful analytics charts
- **Google Fonts** — Playfair Display + Inter

## 🚀 Getting Started

### 1. Clone the repo
```bash
git clone https://github.com/gauri1023/study-sphere.git
cd study-sphere
```

### 2. Open with Live Server
Open `login.html` with VS Code Live Server or any local server.

### 3. Sign up & start studying!
Create an account and your data will sync across all your devices ☁️
